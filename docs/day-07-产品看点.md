# Day 7 · 产品看点（批量详情图）（2026-11-18）

> 需求：产品详情页在「规格参数」「资料下载」之外，新增「产品看点」栏目，支持**批量图片**展示（参考淘宝商品详情的长图堆叠）。
> 验收：后台可批量上传并排序；前台详情页按顺序全宽展示，带图片说明，图片缺失时降级不破版。

## 1. 数据结构

| 项 | 内容 |
|---|---|
| 字段 | `cms_product.detail_images`（`json`） |
| 格式 | `[{"url":"/profile/...","caption":"大风量 · 爆炒不跑烟"}, ...]` |
| 脚本 | `sql/10-product-detail-images.sql`（幂等：列已存在则跳过） |
| 演示 | `06-demo-data.sql` 追加了产品 1（3 张）、产品 2（1 张）的看点数据（占位路径） |

## 2. 后台（产品管理）

产品编辑弹窗新增「产品看点」区域：

| 功能 | 说明 |
|---|---|
| 批量上传 | 多选图片一次上传（≤20 张），自动追加到下方列表；上传后组件自动清空，可以继续追加 |
| 缩略图 | 每行显示 72×54 缩略图（经 `/dev-api/profile` 代理预览） |
| 图片说明 | 每张可填 caption（可空） |
| 排序 | 「上移 / 下移」调整顺序（保存后前台按此顺序展示） |
| 删除 | 单张移除 |
| 提交 | 自动转成 JSON 写入 `detail_images`；空列表存 `null` |

## 3. 前台（产品详情）

- 位置：图集/卖点 → **规格参数** → **产品看点** → 资料下载 → 相关推荐
- 样式：容器内全宽堆叠（`width:100%`）、图片圆角、说明居中、`loading="lazy"`
- 兼容：Windows 反斜杠路径归一；`/profile` 按 `VITE_API_BASE` 拼接；加载失败自动替换占位图，不会出现破图
- 接口：`GET /api/site/product/{id}` 新增 `detailImages: [{url, caption}]`

> 演示数据里的 `/images/detail/*.jpg` 是占位路径，页面会显示灰底占位图 + 说明文字。**在后台「产品看点」批量上传真实图片后即可看到实际效果**（图片会持久保存在 `site/uploadPath`）。

## 5. 使用建议

1. 详情图建议宽度 **1200px 以上**，前台按容器宽度自适应，不会裁切；
2. 一段卖点配一张图 + 一句说明，淘宝式阅读节奏最好；
3. 图片多时建议先压缩（WebP）再上传，后续接 OSS 可自动按宽度出图；
4. 图集（≤9 张）用于顶部主图/悬停图；看点图用于下半部分长图，两者互不影响。
